# Portafolio personal

Página web de presentación y experiencia profesional de Nicolás Marín Colorado.

## Tecnologías

HTML5, Tailwind CSS por CDN, CSS3 y JavaScript.

## Archivos

- `index.html`: contenido del portafolio.
- `css/styles.css`: estilos complementarios.
- `js/main.js`: menú móvil y navegación activa.
- `img/foto.jpg`: fotografía de perfil.
